replay, feature flags, experiments, surveys, error tracking, a data warehouse,
and more. The rest of this guide walked through several of them: events and
autocapture, insights and dashboards, session replay, feature flags,

where this project actually stands.

## Top 3 things to try next

The rest of the guide covered events, insights, replay, flags, experiments,
and surveys. Here are three more products this project hasn't touched at
all.

<CardGrid>
	<Card title="Error Tracking" icon="error">
		Already switched on for this project, just waiting on its first
		exception. Throw one on purpose, an unhandled error in a script tag is
		enough, and watch it turn into a grouped, symbolicated issue instead of
		a line buried in the browser console.
		<a data-recommendation="error-tracking" href="https://posthog.com/docs/error-tracking/installation"> Read the docs</a>.
	</Card>
	<Card title="Web Analytics" icon="analytics">
		The same `$pageview` events already flowing through this site power a
		dedicated dashboard: top pages, referrers, devices, and countries,
		with no insight-building required.
		<a data-recommendation="web-analytics" href="https://posthog.com/docs/web-analytics"> Read the docs</a>.
	</Card>
	<Card title="Workflows" icon="signal">
		Wire up an automation that fires when this site's own `guide_started`
		event happens, a Slack message, an email, a webhook, without writing
		a backend to do it.
		<a data-recommendation="workflows" href="https://posthog.com/docs/cdp"> Read the docs</a>.
	</Card>
</CardGrid>
